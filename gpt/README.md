# GPT notes

Ten folder służy jako miejsce na notatki i zrzuty generowane z rozmów w ChatGPT Web.

## Do czego służy

- zapisywanie podsumowań rozmów jako pliki Markdown (`.md`),
- odkładanie wniosków, researchu i krótkich notatek z ChatGPT,
- tworzenie nowych notatek bez ręcznego kopiowania treści z czatu,
- późniejsze przeglądanie i edycja tych plików w Obsidianie,
- synchronizacja zmian przez Git.

## Założenie workflow

1. Rozmowa lub research odbywa się w ChatGPT.
2. Gdy warto coś zachować, ChatGPT zapisuje wynik jako plik `.md` w tym folderze albo w innym wskazanym miejscu repozytorium.
3. Obsidian pobiera zmiany przez Git i pokazuje je jak zwykłe notatki.
4. Notatki można dalej edytować ręcznie, linkować z innymi plikami i porządkować w Obsidianie.

## Zasady

- Ten folder może pełnić rolę prostego inboxa na zrzuty z ChatGPT.
- Nazwy plików powinny jasno opisywać temat rozmowy.
- Warto zachowywać sensowną strukturę nagłówków Markdown.
- Jeśli dany temat ma już własną docelową notatkę w repozytorium, lepiej aktualizować ją zamiast tworzyć duplikat.
